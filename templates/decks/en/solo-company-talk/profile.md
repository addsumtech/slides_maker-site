# The Solo Operator — "The One-Person Company & AI"

An opinion-driven personal talk deck (12 slides, 16:9, English) built as a front-door
example for the slide-maker template gallery.

## Template File

`template.pptx` — 12 slides, fully native and editable (real text, shapes, icons; no
flattened images). Rebuildable from `build_solo_company.py` (the source of truth).
Per-slide PNGs in `render/` (`slide01.png` … `slide12.png`).

## Summary

A confident, editorial trend-talk template for a *personal* presentation — the kind of
deck a builder or solopreneur gives about a shift they see coming. This example argues
"one person can now run like a company because AI creates leverage," but it is really a
**reusable visual system**: the words are a real, fact-checked example, not placeholders,
so you can **keep the design and swap in your own content**.

Use it for: trend / point-of-view talks, conference or meetup keynotes, personal essays
turned into slides, internal "here's where this is going" briefings, thought-leadership.

What makes it reusable: a warm-paper interior canvas with **dark statement bookends** for
rhythm; a strict **two-colour semantic contract** (one hue = you/the human, one hue = the
machine/tools) that carries meaning on every slide; a **signature motif** (one core, many
rings) that appears as cover art, a footer brandmark, and the close; and a deliberately
**varied form vocabulary** (statement, stat + pull-quote, feature cards, a leverage taper,
a hub-and-spoke org chart, a pipeline with a feedback loop, an icon stack, a contrast
split, a risk register, an editorial term list, numbered steps). Replace the copy, keep
the system, and the deck stays coherent.

## Structure

1. **Cover** — dark statement + signature motif; "The One-Person Company."
2. **The shift** — dark hook; Altman pull-quote + the Census ground-truth (30.4M / $1.8T).
3. **Why now** — three forces that collapsed the cost of a company (teal icon cards).
4. **The leverage ladder** — labor → capital → code & media → AI, as a value taper + rail.
5. **You are the org chart** — dark peak; hub-and-spoke, YOU at the core, six AI-run functions.
6. **A day in the loop** — a real workflow pipeline (teal AI steps, ember human step) + loop.
7. **The stack** — the real tools, grouped by function (two-column icon list).
8. **The reallocation** — the bottleneck moved: many tasks go near-free, judgment gets scarce.
9. **Limits & risks** — an honest 2×3 register (ember = the human-side downside).
10. **The human moat** — what AI can't rent: taste, judgment, relationships, accountability.
11. **What to do Monday** — start with one loop (numbered steps) + a dark closing card.
12. **Close** — dark bookend mirroring the cover; "You are the org chart now."

## Fonts & Colors

**Fonts** (portable macOS system faces; substitute if opening elsewhere):
- Display + body: **Avenir Next** (warm geometric humanist; lining figures read clean at hero size).
- Pull-quotes / glosses / standfirst: **Palatino**, italic (the editorial serif accent).
- Mono chrome (eyebrows, tool names, edge labels): **Menlo**.

**Colors** — a two-hue semantic contract on neutral canvases:
- `PAPER #F4F1E9` — warm off-white interior canvas.
- `INK #1B1C1F` — near-black warm body ink.
- `DARK #15161B` — statement-slide canvas (cover, hook, org-chart peak, close).
- `EMBER #E1542A` — **the human / you / leverage / the judgment call** (emphasis hue).
- `TEAL #168581` — **AI / automation / tools** (the machine hue).
- `TAUPE` ramp `#C9C2B2 · #B6AE9D · #A39B8A` — neutral bands (e.g. the non-AI ladder rungs).
- `MUTE #8C8578` — warm grey for captions, footers, source notes.

Each hue means one thing deck-wide: ember never labels a tool, teal never labels the human.
The signature motif (ember core, teal rings) encodes the whole thesis — one operator, a
fleet of AI — and recurs as the deck's identity mark.
