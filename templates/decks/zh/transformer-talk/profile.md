# 学术编辑体 · 论文精读 Deck 模板（Transformer 示例）

## Template File
`template.pptx` —— 15 页，16:9（10 × 5.625 in），全中文，原生可编辑（真实文本 / 形状 / 原生图表 / 排版公式，无 AI 生成配图）。
配套：`build_transformer.py`（可复现构建脚本，模板的"真源"）、`assets_gen.py`（生成公式 PNG 与真实计算图）、`render/slide01–15.png`（逐页渲染）、`template.notes.txt`（导出的中文演讲备注）。

## Summary
这是一套面向**论文精读 / 实验室组会 / 技术分享**的「学术编辑体」幻灯模板：暖牙白纸面 + 宋体衬线标题 + 无衬线正文 + Computer-Modern 排版公式，配一条贯穿全篇的语义色（朱橙＝本文方法 / 靛青＝对照旧范式）。它刻意避开"模板感"——不用默认蓝、不堆卡片网格，而是用**为内容量身构图的原生图形**表达公式与架构：编码器-解码器架构图、缩放点积注意力公式、多头并行、正弦位置编码（真实计算的热力图）、BLEU 柱状对比、训练算力 meter 对比等，每页形式各不相同。

适合场景：论文分享、方法讲解、课程/教学、研究组会、技术评审等**图解优先、需要公式与结构图**的中文演讲。

**本模板交付的是「真实内容示例」，而非占位符**——正文是对《Attention Is All You Need》的真实精读，所有数字均已联网核实。复用时把它当作一套**可迁移的视觉系统**：保留版式骨架（纸面底、衬线标题、mono 眉标、语义色、注意力连线母题、原生图/公式/图表的组件用法），把文字与数据替换成你自己的主题即可。改动请编辑 `build_transformer.py` 重跑，而非手改二进制，以保证可复现。

## Structure（逐页）
1. **封面** —— 论文名 + 中文副标题 + 作者/出处；右上「注意力连线」母题。
2. **研究背景与问题** —— RNN 隐藏态顺序链 + 长程依赖弧；三张痛点卡（图标）。
3. **核心主张** —— 大字断言"抛弃循环与卷积，仅凭注意力"，三张后果卡 + 原文引句。
4. **复杂度之争** —— Table 1 三类层复杂度对比表（高亮自注意力行）+ O(1) 要点栏。
5. **模型架构总览** —— 原生编码器/解码器堆叠图（子层 + ×6 + 跨注意力虚线 + 嵌入/位置编码）。
6. **缩放点积注意力** —— CM 排版主公式 + Q/K/V 释义 + 四步计算流。
7. **为何除以 √dₖ** —— 因果四步 + 真实计算的 softmax 权重分布对比（原生图表）。
8. **多头注意力** —— 8 个头的并行 pattern（repeat_row）+ Concat/W^O 公式 + 三条理由。
9. **位置编码** —— 正弦/余弦公式（CM）+ 真实计算的位置编码热力图（deck 配色）。
10. **关键配置与训练** —— base / big 双规格 spec 卡 + 统一训练设置条。
11. **实验结果** —— WMT'14 英→德 BLEU 零基柱状图（橙色高亮 big）+ 数字要点栏。
12. **训练效率** —— 三个大数字 + "所以"洞见条 + 英→法训练算力 meter 对比（<1/4）。
13. **局限与启示** —— 左「局限」/ 右「启示」双栏对照。
14. **要点回顾** —— 五句话编号脉络 + 右侧"一句话记住"主题栏。
15. **结束 / 参考** —— colophon 收束语 + 出处；「注意力连线」母题呼应封面。

## Fonts & Colors
**字体（跨平台可编辑）**
- 标题（中文）：Songti SC（宋体衬线，编辑气质）；标题/数字（拉丁）：Helvetica Neue。
- 正文（中文）：Hiragino Sans GB（macOS 渲染安全、字重清晰）；拉丁正文：Helvetica Neue。
- 眉标 / chrome / 页码 / 技术标签：Menlo（等宽，冷静的技术签名）。
- 公式：Computer Modern（经典 LaTeX 观感），经 `equation_png` 光栅化——**字体无关、免 tofu**，任何机器打开都一致。
- 提示：换机时若无 Songti SC，中文标题会回退；可在 `set_palette(eadisplay=...)` 改成 Hiragino Sans GB。

**配色（语义契约——一色一义，贯穿全篇）**
- 纸面底 `#F4F1E9`（暖牙白）· 卡面 `#FBFAF6` · 墨黑正文 `#1C1D22` · 次级正文 `#5A5E68` · 暖灰 chrome `#6F6656` · 暖色分隔线 `#D9D2C4`。
- **朱橙 `#B84020` = 注意力 / 本文方法 / Transformer**（签名信号色，贯穿标题眉标、强调、高亮）。
- **靛青 `#16656B` = 旧范式（RNN/CNN）/ 对照基线 / 顺序计算**。
- 藏蓝 `#2A3F57` = 结构中性（前馈网络、结构块）· 赭黄 `#B0873E` = 第三类别点缀。
- 所有正文文字对底色对比度 ≥ 4.5:1；朱橙作为小字亦满足 ≥4.5:1。
