# NVIDIA — 公司与产品总览

一份面向 slide-maker 公开模板画廊的旗舰级示例 deck：以一份真实、经过事实核查的
「公司与产品总览」呈现，而非填充占位文字的样板。它既展示了一份精致的公司简介 /
产品矩阵 / 客户沟通型 deck 长什么样，本身也是一套可复用的**视觉系统**——你可以保留它，
把自己公司的内容灌进去。

> 本文件是英文版 deck 的**中文版**：同一套设计，只换语言。版式、配色、字号层级、
> 组件、页数与视觉系统全部保持不变，仅将构建脚本中的文字逐一译为地道中文；数字、年份、
> 专名与来源一律未改。

## 模板文件

- `template.pptx` — 可编辑的 16:9 deck（原生文字、图形与图表，在 PowerPoint / Keynote
  中完全可编辑）。
- `render/slide01.png … slide16.png` — 每页一张 PNG（版式样张）。
- `build_nvidia.py` — 作为源真相的构建脚本（重跑即可再生成整份 deck）。

## 概览

**它是什么。** 一份 16 页的 NVIDIA 中文总览——公司概况、里程碑、全栈平台、商业模式、
营收，四大产品支柱矩阵（数据中心 / 游戏 / 专业可视化 / 汽车与机器人）、CUDA 软件护城河、
竞争格局，以及一块关键数据记分板。每一项数字都**对照一手来源联网核实**（NVIDIA 的 SEC
文件与新闻稿、GTC 2025、Jon Peddie Research、市值追踪站），数据截至 2026 年 7 月；任何
无法锁定到干净来源的内容（例如 AI 加速器市场份额）都**以定性方式**表达，绝不编造。

**它适合哪里。** 面向任何科技公司的公司简介、投资人 / 合作伙伴总览、产品矩阵简报与
客户沟通型 deck——尤其适合想要一种自信、带工程气质的深色观感的场景。它被刻意设计成一份
**可自读的参考件**：每一页无论在屏幕上还是作为 PNG，都能独立成立。

**如何复用。** 把*内容*当成一个做好的范例，把*视觉系统*当成可复用的资产。保留结构、
chrome、语义配色契约与组件选择，用你自己的事实替换掉 NVIDIA 的。调色板、字标、
「compute-grid」签名 motif 以及各支柱的配色，全部只在 `build_nvidia.py` 里定义一次，
所以换皮到另一个品牌只是几处编辑——改强调色、改字标文字、改数字，整份 deck 就会重新换主题。
真实内容范例的意义正在于此：一套可信赖的、经过验证的视觉系统，配上你可以随手替换的内容。

## 结构

1. **封面** — 「加速计算的代名词。」+ 定位句与数据截止日期。
2. **公司概况** — 身份事实（成立、创始人、CEO、模式）+ 一块头条数据面板（营收、市值、
   净利润、研发）。
3. **全栈平台** — 主张：NVIDIA 卖的是整套技术栈（芯片 → 系统 → 网络 → 软件 → 生态），
   以分层图呈现。
4. **里程碑** — 1993–2025 的交替式时间线，外加一条「三时代」总结条。
5. **AI 拐点** — 营收轨迹柱状图（FY2023–FY2026，总营收 vs 数据中心），配「$15B → $194B」
   要点栏。*（钱页 / money slide。）*
6. **商业模式** — 设计 → 制造 → 集成 → 软件 → 部署的价值链，外加「如何赚钱」与
   「护城河为何稳固」两栏。
7. **分部营收** — FY2025 环形图 + 排行榜，展示数据中心的主导地位。
8. **产品线矩阵** — 四大硬件支柱以 2×2 卡片呈现，下方一条横贯的 CUDA 软件带。
9. **数据中心与 AI** — 架构路线图（Ampere → Rubin）+ 一块 GB200 NVL72 规格面板与
   完整数据中心技术栈。
10. **游戏** — GeForce RTX 50（Blackwell）与 DLSS 4（「最高 8×」）。
11. **专业可视化** — Omniverse 数字孪生闭环（现实 → 孪生 → 仿真 → 部署）+ RTX PRO 与
    「为何重要」。
12. **汽车与机器人** — 三层「物理 AI」堆栈（Isaac / Jetson Thor / DRIVE）。
13. **护城河** — CUDA：「约 600 万开发者」的 hero 数字 + 锁定效应的软件分层。
14. **竞争格局** — 市场份额进度条 + 挑战者面板（AMD / Intel / 自研芯片）。
15. **关键数据** — 六块 KPI 记分板磁贴。
16. **收尾 + 来源** — 「一套平台，从图形到 AI 工厂。」+ 一条来源信息带。

## 字体与配色

**字体。** 一套刻意选择的、跨平台可移植的搭配，让 `.pptx` 在各处渲染一致；中文版在其上
增加一款受控的东亚字体，使中文字形不出现豆腐块（tofu），而拉丁字母与数字仍保持在 Arial：
- **展示与正文：** Arial（标题 / hero 用粗体，正文用常规）——等线数字让众多大数保持干净、
  基线对齐。
- **中文（东亚字体）：** Hiragino Sans GB——通过 deckkit 的 `EAFONT` 机制，仅对中文字形
  生效，拉丁字母与数字不受影响（该字体在 macOS 渲染流程中稳定可靠）。
- **chrome / 等宽：** Consolas——「>_」加字距的眉标、页脚标签与页码，营造安静的
  「工程终端」气质。（若缺失 Consolas 会回退到默认等宽字体；可将 `deckkit.MONO` 换成
  本机已装的等宽字体来控制。）

**配色。** 近黑画布 + 一种签名品牌色，配一套严格的语义契约：
- **画布：** `#0B0E10` 近黑（base）与 `#07120B` 绿黑（hero / 封面 / 封底）。
- **面板与线条：** `#141A1E` 面板、`#2A343B` 细线；ink `#EDF2EE`；muted `#94A0A2`。
- **NVIDIA 绿 `#76B900`**（小字用更亮的 `#9BE01E`）——*那个*品牌色，绑定公司、数据中心
  与增长故事。它是全 deck 唯一的主强调色。
- **各支柱专属色，只用于各自支柱：** 青 `#2FB6E6` = 游戏 · 紫 `#A585F5` = 专业可视化 /
  Omniverse · 琥珀 `#F2A93B` = 汽车与机器人 · 钢灰 `#7C8A92` = OEM / 中性 / 对手。

配色在这里承载语义：同一种色在全部 16 页里始终代表同一件事——这正是让整份 deck 读起来
像「一套系统」而非「一堆风格各异的页面」的原因。

> **字体说明：** 本模板用了 macOS 系统字体（中文 Hiragino Sans GB / PingFang SC / Songti SC，拉丁 Helvetica Neue / Avenir Next / Georgia）。在 Windows 等系统上，装 **Noto Sans CJK SC / 思源黑体** 即可还原原貌，否则打开时会自动替换为系统字体。在线预览是像素级渲染图，无论你本机装没装字体都显示正确。
