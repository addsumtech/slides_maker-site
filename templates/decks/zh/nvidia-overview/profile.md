# NVIDIA 公司与产品概览 — 深色工程视觉系统（示例 deck）

## Template File
`template.pptx`（16:9，16 页，中文，原生可编辑；配套逐页渲染图见 `render/slide01.png … slide16.png`）

## Summary
这是一套面向**公司/产品概览**场景的深色「工程感」演示模板，以 NVIDIA 为**真实内容示例**做满：公司概况、发展里程碑、关键数字、财务与营收结构、产品线矩阵、数据中心全栈、软件生态与 CUDA 护城河、商业模式、竞争位置、风险挑战、收束与数据来源。

适用场景：**公司介绍 / 产品矩阵讲解 / 客户与投资者沟通 / 行业科普**——任何需要在十几页内把「一家公司是什么、做什么、凭什么、风险在哪」讲清楚的对外材料。

**重点：这是「真实内容示例 + 可复用视觉系统」。** 所有文字与数字都是真实、经公开来源核实的内容示例（截至 2026 年 7 月），不是占位符；而真正可复用的是这套**视觉系统与版式语言**——把里面的 NVIDIA 内容替换成你自己公司/产品的事实，即可直接产出同等质感的概览 deck。每一页都是一种「内容形状 → 版式」的范例：大数字宫格、原生柱状图/环图、交替时间轴、bento 卡阵、分层堆叠图、同心环护城河、飞轮回路、份额条、风险行表。

## Fonts & Colors

- 主文字 `#EAF0EC`；次文字 `#94A29B`；极弱 `#5C6A64`
- **NVIDIA 绿 = 语义主角色**：亮绿 `#8CC63F`（文字/图标/标签）、真绿 `#76B900`（填充/规线/主柱）。全篇绑定同一含义——NVIDIA 本身 / 领先 / 每张图里「最重要的那条数据」

- 签名动机「机架栅格」：封面/收束页的极淡竖线纹理，呼应服务器机架 / 硅片栅格；标题下绿细规线、绿机架刻度作列表 marker
