# 明亮教学风 · 企业内训课件模板（《结构化表达与汇报》示例）

## Template File
`template.pptx`（16:9，16 页，中文，原生可编辑；配套逐页渲染图见 `render/slide01.png … render/slide16.png`，构建脚本见 `build_corporate_training.py`）

## Summary
这是一套面向**成人培训 / 企业内训 / 工作坊课件**场景的**明亮教学风**模板，以一门真实可讲的课——《结构化表达与汇报》——为**真实内容示例**做满：课程目标与适用人群、为什么「说不清楚」是个真问题、三个方法的框架总览、SCQA / 金字塔 / MECE 逐个讲解并各配一页「改前 / 改后」对照、两次现场练习、五个常见坑复盘、一页速查卡、行动清单与出处页。

适用场景：**企业内训、新人培训、工作坊、内部分享、认证课程、师训、高校通识课**——任何需要在十几页里**先讲清楚、再让学员当场动手、最后让他带走一张可执行清单**的教学材料。它同时是**现场投影稿**与**课后讲义**：每页都写了讲师口述脚本（speaker notes），页面本身在没有讲师的情况下也能独立读懂。

**重点：这是「真实内容示例 + 可复用视觉系统」。** 课上所讲的方法论均有公开、可核实的出处，逐条标注在 P16（Barbara Minto 1987 / 1996、麦肯锡校友访谈、Miller 1956、Cowan 2001），核实日期写在页上；查不到出处的一律不写——比如「电梯演讲」一词来源说法不一，课件就只借用其形式并明写**不作出处断言**。课件里的邮件、汇报、分类范例是**为演示结构而写的虚构教学场景**，每一页右上角都标注，P16 再声明一次，绝不伪装成真实企业数据。而真正可复用的是这套**教学版式语言**——把里面的课程内容换成你自己的，即可直接产出同等质感的课件。

这份模板要证明的一件事：**教学节奏可以被视觉制度化。** 学员不需要听讲师说「现在开始练习」，页面自己会说：

- **一色一义的三功能色**——教学蓝＝讲授 / 芥末黄＝练习 / 砖红＝警示。这三个色在页脚徽章、底部课时条、页内强调里同步使用，**没有第四个语义色**（封面与出处页属于中性语域，走灰，不参与语义）。
- **底部 16 格课时条（安静签名，走所有页）**——每格是一页，按该页模式着色；当前格加高、转深，页码就写在格子里。逐页验证当前格严格每页推进一格、与页脚模式徽章同步。翻到任何一页，底边这条就是整堂课的节奏表：黄色那两格，就是你要动手的地方。**两格练习黄与一格警示红在内页保持满饱和，讲授格与中性格降为淡色**——地标必须在任何距离上都认得出来，否则这条尺就退化成一条谁也不会解码的装饰虚线。封面把这条尺放大、把第 1 格按「当前页」样式画出来并附三色图例，学员第一眼就学会读它。
- **练习页与讲授页一眼可辨**——讲授页一律白底，视内容配规线与右栏 rail；**练习页整页变成一张便签**：芥末黄铺到页脚为止、右上折角、没有讲授页那套眉标规线、指令收进右侧白卡而不是 rail、标题字号更大（28pt 对 21pt）。黄色地面上只有一条线——P12 计时器下面那道 5.0in 的黑色重线，它是「硬停」这个动作的视觉锚，不是版式规线。从后排也不会认错。
- **全篇复用的「改前 / 改后」双栏组件**——左＝旧稿灰纸 + ✕，中＝蓝色圆箭头，右＝白纸 + 教学蓝描边 + ✓，下＝「差在哪」注解条。P06 / P08 / P10 三次出现，**外框逐像素相同**（左右卡、圆箭头、注解条的位置与尺寸完全一致），所以三页可以直接横向比较，学员看的是内容差异而不是版式差异；右栏内部按内容排——P06 / P10 是四行等距条目，P08 是一句结论加三条编号理由。

**签名手法（受控的美学冒险）「结论先行条」**——满幅色带**取代**页面标题：话题名缩成色带里的小眉标，**一句话答案本身就是这一页的大标题**。用到它的四页里，标题位上放的都是那一页的答案句而不是话题名：**deck 的形式即它所教的方法**。要说清楚这个手法**不**是什么：它不是把一条 banner 压在标题上方多加一层装饰——那样色带只吃掉眉标的位置，页面还是「话题当标题」。这里色带**吃掉了标题本身**，所以省下来的不是垂直空间（实测带色带的四页内容栏起点 1.10–1.42in，与无色带页的 1.12–1.49in 是同一个区间，构图并没有因此位移），省下来的是**标题这个位置的语义**：一页只能有一个最大的句子，这个手法逼你把它让给答案。P05 首现时带一行自指小注「← 这一句就是「结论先行」」，把这个手法本身教给学员。

同一个装置换成砖红，就是 **P13 警示页**的页头。于是缩略图上三个语域各有画布级的辨识度：**练习 = 满版黄 + 折角（P11 / P12）· 警示 = 白底 + 红带（P13）· 讲授 = 白底**，其中讲授语域里最吃重的三页（P05 / P07 / P09）另戴蓝带。一眼分得出三种页，而不是只分得出「黄的」和「其余」。

每一页都是一种「教学动作 → 版式」的范例：
- **超大步骤序号**（01 / 02 / 03 做到 60pt，数字即版心的锚点）
- **组块压缩带**（12 个散件 → 压缩器 → 3 个组块，把「工作记忆装不下」画成空间事实）
- **金字塔树**（结论块 → 三组同类理由 → 六个事实块，连线粗细区分主干与末端）
- **三条分格尺**（MECE：一条横条上只能有一把尺子——互斥与穷尽被同时画出来，表格做不到）
- **巨字计时**（练习页的 `15` 72pt / `00:30` 108pt；P12 让时间当主角，P11 反过来把计时压小、让三步骤当主角）
- **五行「✕ 错 → ✓ 对 → 规则徽标」行表**（每个坑都指回它违反的那条规则）
- **三张速查卡**（全 deck 唯一由并列卡片主导整页的一页——别处的卡片都是配角 rail 或勾选格；中间那张刻意加高做成实心，因为金字塔管的是主干）
- **便签母题**（小便签＝提示，整页便签＝练习）

## Structure（逐页）
01. **封面** — 课程名 + 三句话卖点 + 时长/形式/产出三行；右侧黄色便签写「请带一份你上周的周报，或一封项目邮件来。整堂课我们只改你自己的东西。」；右列「怎么读这份课件」给出「讲授 / 练习 / 警示」三色图例；底部把课时条放大成整堂课的节奏图，下面一行小字教学员怎么读它
02. **课程说明** — 超大序号 01/02/03 三条目标（先说答案 / 分好组 / 排好序）+ 右栏「适合谁」（三个图标行）与「不教什么」；底部一句唯一的衡量标准
03. **为什么说不清楚** — 12 个散件 →「压缩器」蓝带 → 3 个组块的压缩带图；底部砖红口径条说明 Miller 1956 与 Cowan 2001 是**记忆容量的研究结论，不是「每页最多写几条」的排版规定**
04. **框架总览** — 一张图讲清三个方法各管一段：SCQA 管开场、金字塔管主干、MECE 管每一组的切法；右栏一句顺序说明
05. **方法一 · SCQA** — **签名手法首现**（蓝色结论先行条 + 小注）；四行 S/C/Q/A 各配巨型首字母与一句自检问题，C 行的自检被高亮
06. **SCQA · 冲突在第二句变成一个日期** — 双栏对照组件第一次出现（眉标「改前 / 改后 ①」带场景）；标题是断言不是话题标签，字数由正文实测推导，页面上的数字永远与正文一致
07. **方法二 · 金字塔** — 结论先行条 + 金字塔树（结论 → 三组同类理由 → 六个事实块）+ 右栏三条规则 rail；左下一句「读法」自检
08. **金字塔 · 三个范畴 → 一个范畴** — 同一组件（眉标「改前 / 改后 ② · 一次「要不要加人」的口头汇报」），练规则②（同组必须同类）
09. **方法三 · MECE** — 结论先行条 + 三条「切分尺」分格条（按生命周期 / 按责任方 / 按金额）。第一把尺子的第 4 格「外部变动」刻意画成**描边格**：它不是这把尺子上的一个刻度，是为了「穷尽」而留的**兜底格**，形状上就该与其余三格不同类；金额档用「100 万及以上 / 10 万～不足 100 万 / 不足 10 万」，端点不重叠——教互斥的那一页自己必须互斥
10. **MECE · 两把尺子 → 一把尺子加一个兜底格** — 同一组件（眉标「改前 / 改后 ③」），练互斥与穷尽
11. **现场练习 ①（练习语域首现）** — 满版芥末黄 + 折角；巨字 `15` 分钟 + 三步骤（单独做 / 两人一组 / 全场）+ 右侧白卡「互评只问三个问题」+ 黑色产出条
12. **现场练习 ②（用 30 秒讲一遍你刚改的那件事）** — 同一语域、构图相反：巨字 `00:30` 主导，指令退到右卡；标题直接给题目（练习页不能让学员先举手问「讲什么」），底部注明「电梯演讲」词源不作断言
13. **常见坑（警示语域）** — 满幅砖红页头（与蓝色结论先行条同一个装置，换成警示色）；五行「✕ 错句 → ✓ 改法 → 违反哪条规则」行表，右列五枚徽标恰好覆盖全部三条规则 + SCQA + MECE，构成一张完整的「坑 ↔ 规则」映射表；底部一句收口
14. **一页速查卡** — 三张卡（SCQA / 金字塔 / MECE），各带「管什么 / 要点 / 什么时候用 / 自检问题」；中卡加高做成实心
15. **小结与行动清单** — 大字断言「结构不是为了好看。是为了让对方少花力气。」+ 接下来 14 天四件事的勾选格 + 黄色便签
16. **出处** — 五条编号来源（可核实）+ 右栏口径说明四条（虚构场景声明 / 电梯演讲词源 / 米勒本人对「7」只是巧合的说明 / 三条规则的通行译法）+ 资料核实日期

## Fonts & Colors
**字体（角色化搭配，刻意只有两族）**
- 拉丁 / 数字：**Avenir Next**（几何人文无衬线，教学气质温和但不软；lining 等高数字，`01` / `15` / `00:30` 这些巨字与序号不会高低起伏、不会被拆行）
- 中文：**Hiragino Sans GB**（macOS 渲染安全，字重清晰）。`.pptx` 里只写了这一个字体名、不含回退表；换到没有它的机器上时建议手动替换为 Microsoft YaHei 或 Noto Sans CJK SC。**刻意不用 PingFang**——它在 LibreOffice 下会渲染成手写体
- **没有第三种字体**。眉标、页脚、口径注、徽标全部走 Avenir Next + Hiragino Sans GB，靠**字重与字距（tracking）**区分角色——眉标加 1.6–2.0pt 字距，页脚与白底上的口径注降到三级墨（压在色带上的那几条改用该色带的浅色，见配色）
- 字号 token：`9 眉标/口径 · 11 卡内细节 · 12 范例正文 · 13 正文 · 16 小标题 · 21 页面标题 / 结论先行条 · 28 大字陈述 / 练习页标题` + 四个巨字 `42 封面 · 60 超大步骤序号 · 72 / 108 练习页计时`
- `12` 是一个**刻意的角色号**：「改前 / 改后」卡内的**范例正文**——那是全场一起读的一段字，需要从后排可辨；而 `11` 留给近距离阅读的参考细节。同一页上两者并存不算字号泛滥，是角色区分
- 组件已对每个 run 自动补 `<a:ea>` CJK 字体，中英混排不串字、不 tofu；全 deck 统一开启「盘古之白」（中文与 Latin 之间加空格）

**配色（语义契约——一色一义，贯穿全篇）**
- 画布：**纯白 `#FFFFFF`**；主墨 `#1A1A1A`（17.4:1）· 次墨 `#55555A`（7.4:1）· 三级墨 `#6E6E75`（5.1:1）· 发丝线 `#E3E3E0`
- **教学蓝 `#1A56C4` = 讲授**（6.6:1 on 白；白字压在其上同为 6.6:1）。用于：结论先行条、金字塔与框架图、「改后」栏、页脚讲授徽章、课时条的讲授格。深蓝 `#0F3F9E`、次深蓝 `#2A66CE` 与中蓝 `#3A73D4`（4.58:1）为同族的填充变体，只出现在色块与超大步骤序号上，**不作正文色**
- **芥末黄 `#F5C542` = 练习 / 你要动手**（主墨压在其上 10.7:1）。用于：满版练习页、便签母题、课时条的练习格。深芥末 `#E0AE28` 只画便签折角；练习页右侧白卡里的两条分隔线是 `#C08A00`（标题下的短重线）与 `#E0E0DC`（脚注上的发丝线）；黄色地面上唯一的线是 P12 计时器下的主墨重线；**白底上的黄系文字一律用 `#7A5200`**（6.9:1），芥末黄本身只在黑色卡片上当文字色（10.7:1，P11 的步骤号与「产出」、P12 的「评分」）
- **砖红 `#B23A26` = 警示**（6.0:1 on 白）。用于：常见坑页、口径提示条、课时条的警示格；压在砖红页头上的浅色文字用 `#F8E6E2`（4.9:1）。**它只在需要学员当心时出现，不作装饰**
- 旧稿墨 `#6B6B70`（4.8:1 on `#F4F4F2`）是「改前」栏专用的降调文字色，让改前稿看起来就像一张被翻旧的纸；它坐的中性纸面 `#F4F4F2` 则是全篇通用的中性底（改前栏、P04/P07 的事实块、P13 的 ✕ 例子、P16 口径卡）。改前栏的表头带另用深一档的 `#E4E4E0`，表头字用 `#4A4A50`（6.9:1）；便签母题的落影是 `#ECECE8`
- 三个语域各有一个浅底，用在页脚徽章上：蓝 `#E9F0FE` / 黄 `#FDF4DA` / 红 `#FBEAE6`；蓝浅底另兼卡片与提示条的底色（便签母题不走浅底，它要的就是满饱和的黄）。蓝族另有一个更浅的填充 `#C8D6F0`（P03 的 12 个散件块）、`#C6D6F4`（P09 三条切分尺的贯通基线）和两个压在教学蓝上的浅蓝文字色 `#C5D7F8`（4.56:1，全 deck 对比度的最低点）与 `#D3E1FB`（5.0:1，色带里的眉标与小注）。课时条上非当前页的格子里，讲授蓝降到 `#A9C1EE`、中性格降到 `#DEDEDA`，而练习黄与警示红保持满饱和——这两个地标必须隔多远都认得出；当前页那格再加高并转成该语域的主色，于是一条条纹里同时读出「整堂课的节奏」和「你在哪」。练习页满版黄上的正文用 `#4A4238`（6.1:1 on `#F5C542`）
- **绿色刻意不用**：「改后」用的是教学蓝而不是习惯性的绿——因为蓝在这份 deck 里已经意味着「讲授内容」，而「改后」正是讲授的示范。引入绿会让色义系统从三色变四色，一色一义就破了
- 所有正文文字对其所在底色的对比度均 ≥ 4.5:1（全 deck 439 个 text run 实测，最低 4.56:1），主要色值在构建脚本顶部注明实测值；语义不靠颜色单独承载（练习页同时有满版黄、折角、字号变化与页脚徽章四重编码）

**版式**：12 栏网格（左右外边距 0.58in 对称，栏间距 0.14in）。**页面下缘刻意不整齐**——P04（框架图讲完就停，止于 4.14in）、P15（收尾，止于 4.48in）与 P14（速查卡，止于 4.50in）在版心中段收住、下方留真空白，版心底是 4.86in。`design_intent` 记了五页的收尾意图：P04 / P07 / P15 标 `envelope="upper"`（其中 P07 只有左栏收得高，右侧三条规则 rail 仍走到版心底，标记记的是意图不是结果），练习页 P11 / P12 标 `envelope="full-bleed"`；其余页走默认收尾带——P14 是唯一收得高却没打标记的一页。同理，收尾句的位置也在轮换：通栏填色条（P06 / P08 / P10 ——「差在哪」是对照组件的固有部件，8.84 × 1.028in）/ 0.05in 竖条 + 一句（P02 / P05 / P07 / P09 / P13 走 13pt，P03 的口径注走 9pt 砖红）/ 右栏注释（P04）/ 标题上方的眉标（P14）/ 干脆不设收尾句（P11 / P12 / P15 / P16），不让每一页都以同一条通栏 takeaway 结束。四种标题处理轮换、相邻页不重样：T1 结论先行色带（P05/P07/P09 蓝带，P13 同款换砖红）、T2 左侧竖条（P03/P06/P08/P10/P14）、T3 眉标 + 规线（P02/P04/P16）、T4 满版黄无规线（练习页 P11/P12），封面与小结页（P01/P15）另用一套大字处理。最常用的一种也只占 31%，没有任何一种处理形成模板感；唯一相邻同款是 P11/P12——那是刻意的，两页练习本来就该成对出现。所有自动增高的文本块（注解条、卡内说明、来源列）的位置都由 `measure_text` 实测推导后从版心底倒推，不手挑坐标；构建脚本以 `lint_layout(strict=True)` 收尾，几何 critical 直接抛异常、不落盘。

**图表与图形**：全部为原生形状与文本，可在 PowerPoint 中逐个元素选中编辑。**无 AI 生成配图**——这份 deck 的视觉承载全部由色域制度与原生图形完成，氛围图会稀释「教学节奏被制度化」这个卖点。图标为 **Phosphor duotone 一族**，按所在底色重新着色后光栅化——五枚用教学蓝（P02 rail 卡上三枚、P14 白卡上两枚），压在 P13 砖红页头与 P14 实心蓝卡上的两枚用白，共 7 枚。

**可移植性**：`.pptx` 只存字体名。换机打开若无 Avenir Next / Hiragino Sans GB，会回退到系统默认无衬线（度量略变，网格与版式不塌）。本模板使用 macOS 系统字体 Avenir Next 与 Hiragino Sans GB；在 Windows 上建议替换为 Segoe UI / Century Gothic + Microsoft YaHei，或安装 Avenir Next / Noto Sans CJK SC 以获得一致效果。**全 deck 未使用 PingFang**——它在 LibreOffice 下会渲染成手写体。修改请编辑 `build_corporate_training.py` 重跑，而非手改二进制，以保证可复现。
