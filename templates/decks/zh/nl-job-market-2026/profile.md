# 荷兰 2026 就业市场数据分析 · 数据社论模板

## Template File
`template.pptx`（13 页，16:9，中文，原生可编辑）。配套：`render/slide01–13.png`（逐页预览）、`build_deck.py`（可复现构建脚本，真源）、`运行记录.md`。

## Summary
这是一套面向**行业研究 / 趋势解读**的「数据社论（Data Editorial）」演示模板，用一份真实、可核查的示例内容——**荷兰 2026 年就业市场数据分析**——把整套视觉系统跑通。它适合任何需要「用数据讲一个判断」的场景：市场/行业报告、政策解读、投研简报、公司对外的趋势洞察、白皮书节选。

模板的核心主张是「**真实内容示例，可复用视觉系统替换内容**」：页面里的每个数字都经过公开数据核实并标注口径（失业率、空缺、薪资、签证门槛、区域、兼职率、预测缺口……来源见第 13 页），预测类与市场行情类均显式标注「预测/非官方」。你可以**保留这套视觉系统（版式、语义配色、组件、节奏），把内容替换成自己的主题**——改 `build_deck.py` 里各页函数的数据与文案即可重跑出同款质感的新 deck，不必从零设计。

适合：想要「有作者气质、非套模板感、图表可编辑、事实经得起推敲」的中文数据型演示。不适合：需要大量摄影/AI 配图的品牌视觉片（本模板刻意零配图，只用原生图形 + 原生图表 + 开源图标）。

## Structure（逐页）
1. **封面** —— 大标题 + 签名母题「紧张度标尺」+ 三个先导数字（3.9% / 91 / €48,000）。
2. **一页概览** —— 深色 KPI 仪表盘，6 张扁平深色卡承载核心数字（失业率、空缺、紧张度、最低时薪、模态年薪、2030 缺口）。
3. **宏观形势** —— 「低失业悖论」：3.9% 失业率 + 91:100 紧张度标尺 + CBS 劳动力双向流动。
4. **空缺结构** —— 37.8 万空缺去向；三大行业 >50%；最缺人的四类行业图标卡。
5. **紧缺行业** —— 医疗 / ICT / 技术工程 / 教育 四格，每格一条核实证据 + 开源图标。
6. **薪资水平** —— 三个官方参照点原生柱状图（中位/模态/平均）+ 最低时薪 + 招聘市场行情（标注非官方）。
7. **国际人才** —— 高技能移民签证工资门槛阶梯（≥30 / <30 / 应届·高教），原生量条。
8. **政策收紧** —— 30%→27% 时间轴 + 两张 before→after 变化卡 + 解读横幅。
9. **区域差异** —— 兰斯塔德 / 布雷恩港 / 其他地区三区对比 + 「13 个极度紧张区」头条带。
10. **结构特征** —— 「兼职之国」：38.6% 兼职率 + 60% 女性兼职 + FTE 解读。
11. **趋势展望** —— 深色，2030→2035 预测（140 万缺口 / 老龄化 / 劳动力增长 / AI），全部标注来源。
12. **结语** —— 「紧、贵、正在收紧」：给求职者 / 雇主 / 政策制定者三类读者的行动要点。
13. **数据来源与口径** —— 主要来源清单 + 口径说明（时点/时期、实测/预测、含/不含、官方/市场）。

## Fonts & Colors
**字体**
- 标题 / 正文（中文）：Hiragino Sans GB（macOS 自带；可替换 Microsoft YaHei / Noto Sans CJK SC）。
- 数字 / 拉丁：Helvetica Neue（等高数字 lining figures，适合大字号量级；缺失回退 Arial）。
- 章节眉标 / 页码：Menlo（等宽，作为「技术台账」气质的签名字体）。
- 层级靠**字号 + 字重 + 颜色 + 字距**拉开（CJK 无真斜体），标题恒大于正文。

**配色（语义配色 —— 一色一义，全篇一致）**
- 暖纸底 `#FAF6EF` + 深孔雀墨 `#14323C`（正文 `#44545B`、说明 `#6E6A5C`）。
- **橙 `#CE5522`（荷兰橙）= 主角**：需求 / 紧缺 / 市场热度（标题细线、关键数字、紧张度标尺母题）。
- **青 `#2C7681` = 政策 / 国际人才 / 供给**（时间轴、门槛量条、供给侧证据）。
- **金 `#A8791F` = 薪资 / 货币**（严格只用于钱：最低时薪、模态年薪、薪资页）。
- **中性分类色**（板岩蓝 `#5E7E88` / 紫灰 `#86697A`）：当一页出现 3–4 个并列类目（行业、区域、读者）时使用，避免占用语义色。
- 深色页（封面 / 概览 / 展望 / 结语）作节奏事件，扁平深色卡 `#1C3B45`，数字纯白，杜绝渐变浑浊。

**签名母题**：`tick_gauge`「紧张度标尺」—— 一排细刻度、一根橙色读数针，呼应全篇「劳动力有多紧」的主线，封面放大、内页缩小置于右上角作为一致的品牌标记。
