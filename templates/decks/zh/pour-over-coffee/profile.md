# 四个数 · 小红书竖版知识轮播模板（手冲咖啡入门示例）

## Template File

- `template.pptx` — 成品 deck（10 张，小红书 3:4 竖版 7.5 × 10 in，中文）。
- `build_pour_over.py` — **源真相**：重跑即复现整份 deck（每页一个页函数，出处与备注集中在 `SRC` / `ROWS` / `SOURCES_ALL` / `NOTES` 里；四个数字页共用 `numeral_page()`，换数字只改 `NUMBERS` 与调用参数）。
- `render/slide01.png … slide10.png` — 逐页渲染图（1440 × 1920，长边 1920）。

## Summary

**这是什么**：一组小红书图文笔记的竖版轮播模板，用《手冲咖啡入门》做真实内容示例。视觉语言是 slide-maker 内置的 **`poster`（海报大字）**——每张一块饱和色场，按钴蓝 → 荧光黄 → 墨黑 → 信号橙轮转，翻一页换一次颜色；标题和数字用 Impact 与粗黑体排到海报尺度，「字就是画面」，不需要任何图片。

**核心手法：封面许诺，逐页兑现。** 封面只抛一个钩子「一杯好手冲，先记住四个数」，中段一个巨型荧光「4」；第 3、5、6、8 张各用一整页大字兑现一个数（粉水比 1:15–1:17、水温 90–96°C、闷蒸 0:30–0:45、总时长 2:30–3:30），四页数字同一字号、同一基线，翻页时只有数字和颜色在变；左上角「四个数 n/4」计数，读者知道自己翻到第几个；最后一张把四个数收成一张账本式参数表，适合截图保存。编号 01–04 只留给这四个数，器具和口味页刻意不编号，避免数字含义混淆。

**适合什么场景**：小红书 / 公众号 / 朋友圈的「知识型轮播」——入门教程、参数清单、避坑指南、配方卡、学习笔记、产品使用说明。尤其适合「能压缩成几个关键数字」的主题：健身（组数 · 次数 · 组间休息 · 频率）、烘焙（温度 · 时间 · 比例）、理财（比例 · 年限 · 费率）、护肤（顺序 · 用量 · 间隔）。

**为什么可复用**：**真实内容示例 + 可复用视觉系统，换内容即可套用。** 示例里每个数字都有公开出处（SCA 金杯标准、James Hoffmann 在 Hario USA 公开的 V60 配方、Crema V60 指南），出处在页脚与最后一张，给区间不给唬人的精确数；没有「评论区扣 1」「关注领取」之类话术，也没有外链和联系方式。真正可迁移的是这套结构与视觉系统：钩子封面 → 准备页 → N 张大字数字页 → 一张不是数字的「刻度页」→ 带时间点的步骤页 → 对照页 → 参数表收束页。换主题时只需改 `build_pour_over.py` 里的文字、数字与出处，色场轮转、计数眉标、账本表、出处页脚会自动跟随。全部为可编辑的原生文本和形状，没有图片，在任何机器上都能重排、改字、再导出。

## Structure

1. 封面（钴蓝）— 钩子「一杯好手冲，先记住四个数」，荧光黄高亮「四个数」+ 巨型「4」，副标列出四个数的名字但不给答案。
2. 开始之前（荧光黄）— 「先备好器具」，不编号细线清单：滤杯和滤纸 / 细口壶 / 电子秤（最好带计时）/ 磨豆机。
3. 四个数 · 1/4（墨黑）— 大字 **1:15–1:17**：粉水比，25 克粉配 375–425 克水。
4. 不用记数字的一项（信号橙）— 研磨度：中细。五档粗细刻度条，中细实心，「冲得太快往细调 / 太慢往粗调」。
5. 四个数 · 2/4（钴蓝）— 大字 **90–96°C**：水落到粉上时的温度，烧开后放约 1 分钟。
6. 四个数 · 3/4（荧光黄）— 大字 **0:30–0:45**：闷蒸，先倒入粉重 2–3 倍的水。
7. 注水步骤（墨黑）— 「先闷蒸，再分两次注水」：以 0:00 / 0:45 / 1:15 三个时间点为主角，每步配一条水量刻度（一到两成 / 六成 / 加满）。
8. 四个数 · 4/4（信号橙）— 大字 **2:30–3:30**：总时长，从第一次注水算到滤杯滴完。
9. 口味不对怎么调（钴蓝）— 上下对照：**偏酸** → 磨细一点或水温调高；**偏苦** → 磨粗一点或水温调低；先把时长调进区间，再按口味微调，一次只改一处。
10. 手冲参数表（荧光黄）— 账本式收束页：01–04 四个数 + 「＋ 研磨度」，每行一句做法，底部四行完整出处。

## Fonts & Colors

**字体（角色化搭配）**
- 大字 / 数字 / 编号：`Impact`（poster 视觉语言的显示字，数字用它排到海报尺度，等高等宽、远看也清楚）。
- 中文标题与正文：`Hiragino Sans GB`（冬青黑体；标题用粗字重做「海报黑」，正文常规字重，手机小屏清晰）。**不使用 PingFang**。
- 西文正文与出处：`Arial`；页码与编号小字：`Courier New`（kit 的 meta 字）。
- 字号阶梯：封面巨型「4」320pt → 四个数字页统一 114pt（同字号同基线）→ 标签 52pt → 页内标题 44pt → 说明 15–22pt → 出处 11pt（手机上约 8pt，安静但可读）。

**配色（语义约定 · 色场即翻页节奏）**
- 色场按页轮转：钴蓝 `#1F3BFF` → 荧光黄 `#D7FF3B` → 墨黑 `#141414` → 信号橙 `#FF4B1F`，四页一循环，任何一页的文字色都按它自己的色场挑选（≥4.5:1）。
- 墨色 `#141414` / 米白 `#F3F0E8`：正文与大字，随色场深浅互换。
- 强调色只做一件事——**可以照做的动作或数值**：钴蓝页上的荧光黄（「→ 磨细一点……」），荧光黄页上的钴蓝（参数表里的四个数值）。
- 刻意不用咖啡棕：让每张卡在信息流里跳出来，也让这套模板换任何主题都不带「咖啡味」。

**署名母题**：「四个数 n/4」计数眉标（器具页是 0/4）+ 只给四个数用的 01–04 编号，最后在参数表里收拢成一本小账。

> 字体替换说明：`Hiragino Sans GB` 为 macOS 系统字体；在 Windows 上会回退，建议替换为 `Microsoft YaHei`（微软雅黑）或思源黑体，Impact / Arial / Courier New 两个平台均自带。
