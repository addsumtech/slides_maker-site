# 一人公司与 AI · 个人演讲模板「支点 / The Fulcrum」

## Template File
`template.pptx` — 12 页,16:9(10 × 5.625 in),全中文。配套 `render/slide01.png … slide12.png` 为逐页预览图;`build_solo_ai.py` 为可复现的构建脚本(改内容后重跑即可再生 pptx);`assets/icons/` 为工具栈页所用的开源图标(Tabler,已按配色重着色)。

## Summary
这是一份**观点型 / 趋势演讲**的示例 deck,主题是「为什么一个人开始能顶一家公司,以及 AI 带来的杠杆结构」。它演示的是一套**可复用的作者气质视觉系统**,而不只是一份具体内容——你可以把每页的文字替换成自己的主题,视觉语言(配色 / 版式 / 母题 / 图形组件)照样成立。

适合的场景:个人趋势演讲、行业分享、观点型 keynote、创作者 / 独立开发者的公开分享、播客或直播的配图 deck、任何「少字多图 + 有主张」的中文演讲。

设计取向刻意避开模板感:
- **深浅节奏**:暖纸浅底的「工作页」与近黑深底的「高潮页」(封面 / 立论 / 工作流 / 金句 / 结语)交替,给演讲情绪起伏。
- **语义配色**:整场颜色只表达「谁在做事」——**琥珀 = 人 / 判断 / 品味,青 = AI / 杠杆 / 自动化,珊瑚 = 风险 / 边界**。这让「人 × AI」的主张在每一页都被颜色重复强化(工作流页的人/AI 交替时间轴是这套语义的高光)。
- **签名母题**:每页标题下的**琥珀→青 渐变细线**,是「人 × AI」的缩影,贯穿全场,也在封面 / 金句 / 结语处放大呼应。
- **形态多样**:对比流程、自建杠杆阶梯、成本坍缩行、双证据卡、人/AI 交替时间轴、以「你」为轴心的辐射图、机会↔风险分栏、编号路线、词式方程金句——12 页几乎每页一种主视觉,不靠卡片网格堆砌。

**真实内容,非占位符**:所有事实与数字都经联网核实或定性表达,量级不确定处一律标注「示意 / 方向性」,来源列于结语页与 `运行记录.md`。演讲口播稿写在每页的**备注 / Speaker Notes**里(演示时开 Presenter View 即可看到),幻灯片正面只留短语。

**如何复用**:保留视觉系统,替换文字——把主题句放进封面与金句页,把你的框架放进阶梯 / 辐射图,把你的证据放进证据卡,把你的风险放进珊瑚分栏,颜色语义(人/AI/风险)照旧套用。改 `build_solo_ai.py` 后重跑,或直接在 PowerPoint / Keynote 里编辑(均为原生可编辑文本与图形)。

## Structure(逐页)
1. **封面** — 深底 · 大标题「一人公司与 AI」+ 副题「为什么,一个人开始能顶一家公司」+ 签名渐变线。
2. **立论** — 深底 · Sam Altman「第一家一人十亿美元公司会在哪年出现」的赌局巨句(钩子)。
3. **重新定义** — 浅底 · 旧范式↔新范式对比流程:不是一个人做完所有事,而是一个人指挥一支 AI 团队。
4. **核心框架** — 浅底 · 杠杆四层阶梯(人力 / 资本 / 代码·内容 / AI):越往上边际成本越低、放大倍数越高。
5. **为什么是现在** — 浅底 · 五行能力成本坍缩(过去→现在):专业能力变成趋近零成本的商品。
6. **证据** — 浅底 · 双证据卡:Midjourney(≈40 人 / 零外部融资)与 Cursor(最快 $100M ARR)——营收和团队规模脱钩。
7. **真实工作流** — 深底 · 一天的人/AI 交替时间轴:人负责判断,AI 负责执行。
8. **工具栈** — 浅底 · 以「你」为轴心的辐射图(带图标):把公司拆成可调度的 AI 模块,判断不可外包。
9. **边界与风险** — 浅底 · 机会↔风险分栏(珊瑚语义):一个人 + AI 也有清晰的天花板。
10. **行动建议** — 浅底 · 五步编号路线 + 「1000 铁杆粉丝」旁注:从一个能独自闭环的小事开始。
11. **一句话记住** — 深底 · 词式方程金句:一人公司 = 判断力 × 杠杆(WOW / 情绪峰值)。
12. **结语** — 深底 · 收束呼应封面:去成为那个会用 AI 的一个人 + 来源参考。

## Fonts & Colors
**字体(角色化配对)**
- 标题 / 金句(显示体):**Songti SC**(宋体,书卷 / 随笔气质)+ 拉丁 **Georgia**。calligraphic 宋体作为「演讲声音」贯穿标题与高潮句。
- 正文 / 标签(无衬线):**Hiragino Sans GB**(macOS LibreOffice 渲染安全;可替 Microsoft YaHei / Noto Sans CJK SC)。
- 数字 / 大数:**Helvetica Neue**(等高数字,大数不错位)。
- 眉标 / 页码(等宽):**Menlo**。
- 便携性提示:Songti SC / Hiragino / Helvetica Neue / Menlo 为 macOS 自带;跨平台分发时,非 Mac 机器建议将 CJK 显示体替为 Songti/YaHei、无衬线替为 Noto Sans CJK SC / 微软雅黑,以免缺字回退。

**配色(语义制)**
- 背景:暖纸 `#F4F0E8`(浅) / 暖近黑 `#14130E`(深)。
- 文字:墨 `#23201A` / 正文灰墨 `#4C463D` / 弱化 `#6B6559`;深底文字 `#F2EEE6`。
- **语义三色**:琥珀(人/判断)`#8A620F`(深底亮版 `#ECB24E`);青(AI/杠杆)`#2C6F8E`(深底亮版 `#5FC1E6`);珊瑚(风险/边界)`#AF3F27`(深底亮版 `#EE7B66`)。
- 规则:每个色只绑定一个概念,浅底用「文字可读」的深色版、深底用「更亮」的版本(色相不变、明度随背景调整);正文文字均 ≥4.5:1 对比;卡片纸白 `#FCFAF5`。
