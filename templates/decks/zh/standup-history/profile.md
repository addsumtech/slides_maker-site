# Lights Down —— 文化类编辑体讲解模板

## 模板文件
`template.pptx` —— 13 页，16:9（10 × 5.625 英寸）。预览图在 `render/`（`slide01.png` … `slide13.png`）。可由 `build_standup.py` 复现（构建脚本是唯一的事实来源）。

## 概要
一套**编辑体「文化大报」**模板，作为 slide-maker 范例库的完整示例，以《脱口秀简史》为题材。它的设计语言——**「Lights Down」**——在一束柔和聚光灯照亮的深色舞台上开场、攀至高潮、收尾（一个麦克风母题，一层带噪点的体积光晕），而这段历史本身则在暖色纸面上娓娓道来：*演出时熄灯，记录时用纸*。衬线标题 + 等宽「署名」小字，让它带上一种有作者、有杂志感的气质，而不是套版幻灯片的样子。

它为**文化讲解与轻量演讲**而设计——任何你想当作一段简短、可信、视觉多变的故事来讲的题材：一段历史、一门领域入门、一份「我们是怎么走到这里的」概览、一件博物馆/讲座式的作品。呈现方式是「讲」出来的（每页都在演讲者备注里带一条口播主线），密度是*均衡*的——页面上文字精炼，细节留在备注里。

**这是一份真实内容的示例，不是占位样张：你要复用的是这套视觉系统——换上你自己的题材，把组件留下。** 所有事实均经联网核实；有争议之处（例如谁是「第一个」现代脱口秀演员）以定性方式表述，而非武断断言。可复用的系统才是重点：深/纸交替的节奏、语义配色的契约、编辑体页眉 + 等宽小字，以及那套组件（时间线、before/after、自上而下的树状图、地区台账、概念等式、人物卡、拉引语高潮、版权信息收尾）。把文字换掉，这套 deck 依然立得住。

## 结构
1. **封面** —— 深色舞台，聚光灯 + 麦克风母题；标题、副标题、范例标签。
2. **这门形式** —— 脱口秀*是*什么：一个人，一支麦，一种观点（三根图标立柱）。
3. **起源（1850s–1930s）** —— 歌舞厅、杂耍剧场、巡回演讲；一条横向时间线。
4. **现代形态（1950s）** —— 夜总会把综艺节目变成单人的声音（before → after）。
5. **黄金年代（1950s–60s）** —— Sahl、Bruce、Newhart；喜剧唱片时代，三张人物卡。
6. **革命（1960s 晚期–70s）** —— Pryor、Carlin、Rivers；喜剧成为自传（深色插段）。
7. **繁荣（1972–1992）** —— 先俱乐部后电视；一条里程碑时间线 + 一句繁荣与崩盘的旁注。
8. **风格分岔** —— 观察式 / 金句式 / 另类式 / 叙事式，一张自上而下的树状图。
9. **走向世界** —— 英国、印度、阿拉伯世界、南非、中国；一张按色区分的地区台账。
10. **今天的产业（截至 2026）** —— 流媒体专场、播客、短视频（三股力量）。
11. **一个笑话的解剖** —— 铺垫 → 包袱，外加前提 / 演出来 / 加挂 / 回旋镖。
12. **为什么重要** —— 言论自由（Bruce、Carlin）与一个人声音的亲密（深色情绪高潮）。
13. **谢幕** —— 呼应封面的收尾书挡，附一行精简来源。

## 字体与配色
**字体（可移植——macOS + Windows 均已预装）：**
- **Georgia** —— 标题显示字：大标题、拉引语、人物名、概念等式。
- **Arial** —— 正文（等高数字，让主视觉数字/年份保持统一）。
- **Courier New** —— 等宽「小字」：带字距的大写小标、页码（`03 / 13`）、页脚、版权信息标签。这种打字机味的小字，是模板安静的招牌。
- 全篇中文字符经 `set_palette(eafont=...)` 统一回落到 **Hiragino Sans GB** 渲染，跨平台可用；在非 mac 机器上换成本地 CJK 字体（如 Microsoft YaHei / Noto Sans CJK SC）即可。

**配色系统（一份刻意的语义契约，而非装饰）：**
- **Stage 舞台** `#1A140E`（暖调近黑）· **Paper 纸面** `#F2EBDA`（暖象牙白）—— 承载深/浅节奏的两块底。
- **Ink 墨** `#24211A`（纸面文字）· **Ivory 象牙** `#F1E9D8`（舞台文字）· **Muted 灰** `#8B8271` / `#9C9284`。
- **Stage-red 舞台红** `#B02E24`（纸面上，AA 合规）/ `#D4402E`（更亮，用在深色舞台）= *喜剧演员的越界之声 / 包袱*——唯一的一抹热色，只用在它真正表意的地方（标题里的关键词、麦克风、「再打破它」、拉引语的引号）。
- **Brass 黄铜** `#A9792E` = *时间线*——时间线圆点、年份徽标、年代标记、时间类页面的小标。
- **Hairline 发丝线** `#D8CFB8`，用于分隔线与卡片描边。
- **协调的分类色**（黄铜 / 青绿 `#2E6E64` / 紫红 `#7A4A66` / 橄榄 `#4E6B34` / 灰蓝 `#3B5C7A`）为分支与地区条目按色编码，同时不破坏两色克制原则——都是安静落在纸面上的大地色，刻意避开了那抹被保留的朱红。

> **字体说明：** 本模板用了 macOS 系统字体（中文 Hiragino Sans GB / PingFang SC / Songti SC，拉丁 Helvetica Neue / Avenir Next / Georgia）。在 Windows 等系统上，装 **Noto Sans CJK SC / 思源黑体** 即可还原原貌，否则打开时会自动替换为系统字体。在线预览是像素级渲染图，无论你本机装没装字体都显示正确。
