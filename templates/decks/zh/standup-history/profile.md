# 脱口秀简史 · 深色「俱乐部聚光灯」示例模板

一份文化科普 / 轻松演讲风格的 16:9 示例 deck，为 slide-maker 官网公开模板画廊制作。主题为「脱口秀简史」，全中文、13 页，采用自研的深色舞台聚光灯视觉系统。

## Template File

- `template.pptx` — 最终可编辑 deck（13 页，16:9，全原生 PowerPoint 文本/形状/图标，无一张整页贴图）。
- `build_standup.py` — 该 deck 的构建脚本，是模板的**真正源文件**：改内容 / 换配色 / 加页都改这里再重跑，可复现。
- `render/slide01.png … slide13.png` — 每页渲染图（供预览与版式核对）。
- `assets/icons/` — 构建时抓取并按配色重着色的 Phosphor 图标（麦克风、扬声器、盾牌等）。

## Summary

这是一套**「真实内容示例 + 可复用视觉系统」**的展示模板：页面里全部是经核实的真实内容（脱口秀的起源、美式黄金年代、风格流变、中文脱口秀的兴起、行业现状、为何重要），而不是「标题占位符 / 正文占位符」。它想证明的一件事是——**这套深色聚光灯视觉系统本身是可复用的，只要把文字换成你自己的主题，版式、配色、字体、图标体系都能原样承接。**

适合的场景：文化 / 科普讲解、行业小史、品牌或产品故事、带「作者气质」的轻演讲、任何希望「暖、有质感、不套模板」的深色 deck。它自读友好（正文落在页面上，不依赖口播），也可直接投屏演讲。

复用方式：打开 `build_standup.py`，顶部 `# palette` 一段改配色、`SONG/HEI` 改字体、每个 `sXX_*` 函数改一页内容；保留 `stage()`（聚光灯背景）、`header()`（眉标+标题+短线）、`card()`（卡片）与语义配色约定，换主题后整体气质不变。事实类内容务必替换为你自己核实过的资料。

## Structure（逐页一行）

1. 封面 — 《脱口秀简史》：一个人、一支麦克风，如何成为一门手艺（大标题 + 聚光灯 + 麦克风图标）
2. 定义 — 单口喜剧＝独自面对观众、最低成本地把观察与真话换成笑声（左定义 + 右三特质卡）
3. 名字辨析 — 「脱口秀」只是 talk show 的音译，这门手艺真正的名字是「单口喜剧 / stand-up」（词等式）
4. 起源 — 单口不是被发明的，是从游艺场边缘长出来的（横向时间轴：19C 初 → 马克·吐温 1866 → 查理·凯斯）
5. 美式黄金年代 — 单口成了社会的声音：布鲁斯 / 卡林 / 普赖尔 + 1972 The Comedy Store 俱乐部时代（三人物卡）
6. 风格流变 — 政治讽刺 → 直白坦诚 → 观察式喜剧（宋飞）→ 流媒体专场全球化（琥珀→青瓷渐变色谱带）
7. 中文脱口秀的兴起 — 2012→2024，从舶来品到本土顶流（双列纵向时间轴，含 2023 震荡、2024 双综回归）
8. 中文场的面孔 — 从综艺造星到真正破圈：代表演员 + 2024 双冠军（付航 / 漫才兄弟）+ 女性占比≈39%
9. 行业现状 — 分裂的生态：出圈在综艺、功夫在剧场（左右双世界对比 + 底部「隐忧」条）
10. 手艺解剖 — 拆开一个「包袱」：好笑＝意料之外＋情理之中，铺垫→误导→反转→回扣（编号步骤）
11. 为什么重要 — 最低成本的公共表达 / 社会情绪减压阀 / 把私人经验变共情 / 一种诚实的训练（2×2 图标网格）
12. 收束 — 一个人，一支麦，至今仍是最锋利的表达（与封面呼应的收尾页）
13. 来源与说明 — 事实经公开资料核对，存疑或快速变化处作定性表达（分栏来源列表）

## Fonts & Colors

**字体（角色分工）**
- 标题 / 大字（中文）：`Songti SC`（宋体，Ming 衬线，编辑感与文气）——经核实为真实应用，非回退。
- 正文 / 卡片文字（中文）：`Hiragino Sans GB`（黑体，清晰、渲染稳）。
- 眉标 / 页码 / 页脚 / 年代数字：`Menlo`（等宽，制造「技术/编辑」质感的安静签名）。
- 拉丁数字与英文词：`Helvetica Neue`（正文）/ `Georgia`（编号大字）。
- 便携性提示：三款字体均为 macOS 自带；换到无 `Songti SC / Hiragino Sans GB` 的机器需替换或内嵌，否则中文会回退变形。

**配色（语义约定：一个颜色只表达一件事）**
- 画布底：暖炭黑 `#15120C`（舞台暗场）；卡片 `#221B12`、浅卡 / 轨道 `#2E2617`；分隔线 `#3A2F1E`。
- 文字：主文 `#F3E9D6`（暖奶白）、正文 `#D6CBB2`、说明 / 眉标 `#9C8F76`（暖灰）。
- **琥珀金 `#E9AC43`**（高亮 `#F4CE86`）＝这门手艺 / 聚光灯 / 全片强调色（贯穿）。
- **砖红 `#DA6444`**＝美式脉络（起源、黄金年代、隐忧）。
- **青瓷绿 `#5CAB9B`**＝中文脉络（中文兴起、面孔、剧场）。
- 光照：每页用全画布「径向暖光 + 方向性线性光」两层叠加（`stage()`），随分区切换主色温做节奏，边缘被画布裁切、无硬边光斑；不使用会溢出画布的椭圆 glow。
- 无 logo（中性题材）；所有文字对背景对比度 ≥ 4.5:1。
