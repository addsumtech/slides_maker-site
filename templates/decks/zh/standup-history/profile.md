# Lights Down — 编辑向文化科普模板 · **带氛围图版（中文）**

> **这是「Lights Down」deck 的中文·带图版。** 内容、结构、页数与视觉语言与基础模板完全一致，
> 只做了两件事：（1）把全部页面文字译成**中文**（数字 / 年份 / 人名 / 来源一律不动）；
> （2）沿用基础带图版的做法，把 `moodimg/` 里三张*无字*的喜剧俱乐部氛围图，满铺织进三个暗场
> 「舞台」页——**封面（1）**、**革命分隔页（6）**、**谢幕收尾页（13）**——每张都压一层渐变暗色 scrim，
> 让原生暖金 / 象牙白文字保持清晰。数字、人名、日期、来源均**零改动**；金铜点缀与 SOURCES 行原样保留。
> 其余十页与基础设计完全相同。

## 模板文件
`template.pptx` — 13 页，16:9（10 × 5.625 in）。逐页预览在 `render/`（`slide01.png` … `slide13.png`）。
可由 `build_standup.py` 复现（构建脚本是唯一真源）。氛围图在 `moodimg/`；`su_mic_flip.png` 是
`su_mic.png` 的水平镜像（话筒移到右侧，构建时生成）。

## 概述
一套为 slide-maker 画廊做的**编辑向「文化小报」**示例模板，主题为《脱口秀简史》。设计语言
——**「Lights Down」**——在暗场舞台上开场、抵达高点、收尾（一支话筒母题、一圈抖动噪声的柔和聚光
光晕），而把历史本身放在暖象牙纸上阅读：*演出时灯灭，存档时留纸*。衬线标题 + 等宽「署名条」
chrome，给它一种有作者气质的杂志感，而不是套壳幻灯片的样子。

它为**文化科普与轻演讲**而设计——任何你想讲成一段短小、可信、视觉有层次的故事的主题：一段历史、
一份领域入门、一篇「我们是怎么走到今天」的综述、一件博物馆 / 讲座作品。呈现方式是现场演讲（每页在
备注里带一条讲词），密度取*平衡*——页面文案精炼，细节放进备注。

**这是真实内容示例，不是占位样张：真正可复用的是视觉系统——换上你自己的主题，保留这套组件即可。**
每条事实都经联网核实；存疑点（如谁是「第一个」现代脱口秀）以定性方式表达，而非断言。可复用系统才是
重点：暗 / 纸的节奏、语义配色契约、编辑向标题 + 等宽 chrome，以及那套组件（时间线、before/after、
自顶向下的树、地区台账、概念等式、人物卡、引言高点、题注收尾）。换掉文字，deck 依然成立。

## 逐页结构
1. **封面** — 满铺俱乐部照片（`su_cover.png`：一支孤立的复古话筒、高脚凳、砖墙、暖金聚光，左侧留出暗
   空间）压渐变 scrim；标题、副标题、画廊 kicker 稳落在左侧暗区。
2. **这门手艺** — 脱口秀*是什么*：一个人、一支话筒、一个观点（三根图标立柱）。
3. **起源（1850s–1930s）** — 音乐厅、杂耍剧场、巡回演讲；一条横向纪年时间线。
4. **现代形态（1950s）** — 夜总会把综艺表演变成单人的声音（before → after）。
5. **黄金年代（1950s–60s）** — Sahl、Bruce、Newhart；喜剧唱片时代，三张人物卡。
6. **革命（1960s 晚期–70s）** — Pryor、Carlin、Rivers；喜剧成为自传（暗场过场，铺在满铺、水平镜像的
   `su_mic.png` 上，点亮的复古话筒落在右侧，避开左侧文字）。
7. **繁荣（1972–1992）** — 先俱乐部后有线电视；里程碑时间线 + 一句繁荣与崩塌注。
8. **风格分岔** — 观察式 / 金句式 / 另类式 / 叙事式，做成自顶向下的树。
9. **走向世界** — 英国、印度、阿拉伯世界、南非、中国；一张按色编码的地区台账。
10. **今天的行业（截至 2026）** — 流媒体专场、播客、短视频切片（三股力量）。
11. **一个笑话的解剖** — 铺垫 → 包袱，外加前提 / 扮演 / 加包袱 / 回扣。
12. **为何重要** — 言论自由（Bruce、Carlin）与单一声音的亲密（暗场情绪高点）。
13. **谢幕** — 收尾书挡，铺在满铺的 `su_stage.png`（一座空的暖光俱乐部舞台）上，呼应封面，左侧暗区带一行
    紧凑的来源信息。

## 字体与配色
**字体（跨平台通用——macOS + Windows 均已安装）：**
- **Georgia** — 标题面：大标题、引言、人物名、概念等式。
- **Arial** — 正文（等高数字，让主数字 / 年份保持统一）。
- **Courier New** — 等宽「chrome」：加字距的大写 kicker、页码（`03 / 13`）、页脚、题注标签。这抹打字机气质
  的 chrome 是模板的低调签名。
- **中文** 统一挂 **Hiragino Sans GB**（`<a:ea>` 东亚字体），让汉字在 mac 上稳定渲染；换机可替换本地
  中文字体（如 Noto Sans CJK SC）。人名 / 来源等拉丁字符仍走对应的 Georgia / Arial / Courier New。

**配色系统（一份刻意的语义契约，而非装饰）：**
- **舞台** `#1A140E`（暖近黑） · **纸** `#F2EBDA`（暖象牙）——承载暗 / 亮节奏的两块底。
- **墨** `#24211A`（纸上文字） · **象牙** `#F1E9D8`（舞台文字） · **灰** `#8B8271` / `#9C9284`。
- **舞台红** `#B02E24`（纸上，AA 合规）/ `#D4402E`（更亮，用于暗场）= *喜剧演员的越界之声 / 包袱*——
  唯一的高热点缀，只用在它真正表意处（标题里的关键词、话筒、「打破它」、引言标记）。
- **金铜** `#A9792E` = *纪年*——时间线圆点、年份徽章、年代标记、时间类页面的 kicker。
- **发丝线** `#D8CFB8`，用于分隔线与卡片描边。
- **协调的分类色**（金铜 / 青 `#2E6E64` / 梅 `#7A4A66` / 橄榄 `#4E6B34` / 石板蓝 `#3B5C7A`）为分支与地区
  条目做色编码，同时不破坏双点缀纪律——安静落在纸上的大地色，刻意排除那抹保留的朱红。

> **字体说明：** 本模板用了 macOS 系统字体。在 Windows 上装 Noto Sans CJK SC / 思源黑体即可还原，否则打开时会自动替换。在线预览是像素级渲染图，始终显示正确。
