# 蜡笔小课堂 · 儿童科普 Deck 模板（什么是 AI）

一套面向小学生的暖色「插画绘本」课堂科普模板。示例内容为「给小学生讲什么是 AI」的一堂完整科普课，全部为真实、可讲授的内容示例——**视觉系统可整套复用，只需替换文字与图标即可改做其它儿童科普主题**（如「什么是电」「垃圾怎么分类」「病毒和细菌」）。

## Template File
- `template.pptx` — 12 页，16:9，中文，完全可编辑（原生文字 / 形状 / 图标，无位图截图）。
- `build_kids_ai.py` — 该 deck 的构建脚本（真正的「源文件」，可重跑复现、便于迭代）。
- `illus.py` — 自研的原生插画系统：手绘机器人吉祥物「小 AI」+ 蜡笔涂鸦零件（星星 / 云朵 / 太阳 / 爱心 / 圆点小路 / 对话气泡）。
- `assets/icons/` — 从开源 Phosphor 图标库拉取、按调色板重新上色的图标（一套统一家族）。
- `render/slide01.png … slide12.png` — 每页渲染图。

## Summary
- **这是什么**：一份「儿童科普 / 低龄课堂讲解」风格模板。核心是一套有作者气质、非模板感的**原生插画视觉系统**——暖奶油纸底 + 蜡笔盒配色 + 贯穿全场的机器人吉祥物 + 圆润卡片，营造绘本课堂的亲和氛围。所有配图均为**无文字氛围插画**（原生矢量绘制），图片不承载任何文字或数据。
- **适合场景**：小学 / 幼儿科普课件、少儿编程或 AI 启蒙、亲子讲解、科技馆 / 图书馆少儿活动、面向大众的「零基础」入门讲解，任何需要「孩子能懂、画面可爱」的演示。现场讲授型（每页已附**老师讲稿**，见演讲者备注）。
- **可复用性**：本 deck 是「真实内容示例 + 可复用视觉系统」。**保留整套视觉（配色 / 吉祥物 / 卡片 / 图标处理 / 版式节奏），把每页文字和图标换成你的主题即可**——五段式叙事骨架（生活里的样子 → 打比方讲原理 → 擅长与不擅长 → 怎么相处 → 安全提醒）几乎适配任何「向孩子解释一个事物」的选题。
- **图片策略说明**：本次生图额度不可用，已按预案**全程改用图标 + 原生矢量图形**完成「可爱插画氛围」，不阻塞等待、不使用占位图。

## Structure（逐页）
1. **封面** — 「什么是 AI？」全幅绘本场景：吉祥物挥手 + 太阳云朵星星；暖色天空 bookend。
2. **探险地图** — 本课路线图：蜿蜒圆点小路串起 5 个编号站点（对应五大主题）。
3. **① AI 在生活里** — 6 张图标卡片：语音助手 / 视频推荐 / 拍照美颜 / 翻译 / 游戏 / 地图。
4. **定义** — 三步流程：看很多例子 → 自己找规律 → 学会一项本领；「像见多识广的小朋友」。
5. **② 打比方（核心页）** — 左右平行类比：你怎么认识「猫」 = AI 怎么认识「猫」，都靠看大量例子。
6. **② 练习循环** — 环形图：猜一猜 → 看对不对 → 改进一下 → 再来一次；「像学骑自行车」。
7. **③ 擅长** — 绿色四卡：记性好 / 算得快 / 不知疲倦 / 找规律高手。
8. **③ 短板** — 对话气泡（自信地说错的趣例）+ 三条短板：没真懂 / 会想当然 / 没常识和感情。
9. **④ 怎么相处** — 编号四规则：说清楚 / 自己检查 / 问大人 / 你做主。
10. **⑤ 安全提醒** — 「可以放心做」（绿 ✓） vs 「要小心哦」（珊瑚 ✗）左右对比。
11. **小结** — 五色回顾条，呼应第 2 页地图的五站。
12. **结尾** — 「工具再聪明，做决定的还是你」全幅收尾，呼应封面（bookend）。

## Fonts & Colors
**字体**
- 中文：`Hiragino Sans GB`（正文与标题；圆润、亲和，且在本渲染工具链上安全、覆盖简体全字集）。
- 拉丁 / 数字：`Arial Rounded MT Bold`（「AI」、页码、数字，圆头更可爱）。
- ⚠ 字体依赖：两者均为 macOS 系统字体。在 Windows / 其它环境打开 `.pptx`，请把中文替换为 `微软雅黑` 或 `思源黑体 / Noto Sans CJK SC`，拉丁替换为 `Arial Rounded` 或任一圆体，观感一致。`render/` 里的 PNG 已是正确渲染结果。

**配色（蜡笔盒 · 语义色）** —— 每种颜色在全场只表达一个意思：
- 纸底 `#FFF6EA`（暖奶油）／封面·结尾天空 `#FFE1C4→#FFF3E4`（桃色渐变 bookend）。
- 文字墨色 `#2E2A4A`（柔和深靛，与吉祥物「脸屏」同色）；次要文字 `#8C86A8`。
- **蓝 `#3D9BE9` = AI / 科技**（吉祥物本体）。
- **绿 `#3FC79A` = 擅长 · 安全 · 好**。
- **黄 `#FFC93C` = 学习 · 点子 · 闪光**。
- **珊瑚 `#FF6B6B` = 小心 · 短板**。
- **紫 `#9B7EDE` = 你 · 小朋友 · 做决定的人**。
- 卡片为白底 + 柔和投影；每个语义色配有极浅底色（tint）用于气泡 / 面板；正文对比度 ≥ 4.5:1。
- 签名 motif：手绘机器人吉祥物「小 AI」（多种表情/姿势，作向导，不做重复图章）+ 蜡笔涂鸦点缀（星星·云朵·太阳·爱心·圆点小路）。
