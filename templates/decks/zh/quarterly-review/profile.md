# 基线 · 季度经营复盘 Deck 模板（瑞士网格 / Netflix Q2 2026 示例）

## Template File
`template.pptx`（16:9，14 页，中文，原生可编辑；配套逐页渲染图见 `render/slide01.png … slide14.png`）

## Summary
这是一套面向**企业季度 / 年度经营复盘**场景的**瑞士国际主义（International Typographic Style）网格排版**模板，以 Netflix 2026 财年第二季度（2026-04-01 — 06-30）为**真实内容示例**做满：季度总览、核心指标看板、收入与利润走势、分区域拆解、汇率口径拆解、用户与参与度、成本与效率、利润率桥、超预期与未达标、风险、下季度重点、口径与来源。

适用场景：**季度 / 年度经营复盘、董事会与管理层汇报、投资者沟通、业务线述职、月度经营会**——任何需要在十几页里把「这个季度发生了什么、为什么、接下来盯什么」讲清楚，而且**必须承载大量数字**的对内对外材料。

**重点：这是「真实内容示例 + 可复用视觉系统」。** 所有文字与数字都来自 Netflix 于 2026-07-16 发布的季度股东信及其未经审计合并财务报表，逐条可核实，不是占位符；核实不到的一律不写或改成定性表达。而真正可复用的是这套**版式语言与图表语法**——把里面的 Netflix 内容换成你自己公司的数字，即可直接产出同等质感的复盘 deck。

这份模板要证明的一件事：**一份 deck 可以承载很大的数字密度，并且依然优雅。** 它不靠色块、卡片、图标或配图来「显得设计过」，全部层级都由字号、字重、留白与对齐承担——因此它也是这个画廊里最容易「换内容即可套用」的一份：你只需要替换数字和文案，网格、规线、语义色和图表几何会自动把版面撑住。

每一页都是一种「数据形状 → 版式」的范例：
- **巨字压栏**（把一个数字做成页面的横向规线；规线只画到巨字的**墨迹**边缘为止，间距正好一个栏间距）
- **12 格指标看板**（一屏放下十二项指标，各带同比与口径注）
- **双层 register 图表**（营收柱在上、增速折线自成一条轨道在下，互不打架）
- **共享轴子弹图**（六个季度对同一条目标线；黑段是水平量，红段是与目标的差，同高连续）
- **双 100% 分段条**（存量占比 vs 增量贡献占比上下对齐，错位一眼可见）
- **dumbbell 双读**（报告口径 vs 汇率中性口径，中间那段红色就是汇率影响）
- **delta-only 瀑布**（利润率桥：四段之和在报表内闭合）
- **紧凑三线表**（只有表头上、表头下、表尾三条规线，无斑马纹、无网格线）
- **同轴与非同轴的分离**（分母不同的比例绝不共用一条轴：两个百分比共轴，「十天里有六天」改用十格计数）
- **双栏对照 / 六行风险表 / 编号来源页**

## Structure（逐页）
01. 封面 — 季度经营复盘 / Netflix Q2 2026；顶部红规线 + 底部三事实条（营收 / 利润率 / 自由现金流）
02. 季度总览 — **巨字 `125.6`，其基线即本页横向规线**；线下四栏（营业利润 / 利润率 / 净利 / EPS）+ 公司指引原话口径
03. 核心指标看板 — 4×3 十二格密集指标网格，每格「标签 · 值 · 同比 · 口径注」，无卡片、只用发丝线
04. 收入走势 — 六季度营收柱（零基线，Q3 空心柱 = 公司指引）+ 下层独立轨道的同比增速折线；右栏并列「公司自述的增长来源」与「公司对 Q3 的口径」
05. 利润走势 — 六季度营业利润率共享轴子弹图；黑段画到目标线，红段从目标线接到条尾 = 与目标的差（只对 2026 财年的季度计算）
06. 分区域拆解 — 营收占比 / 增量贡献占比双 100% 分段条上下对齐 + 红色虚线导引 + 七列读数表
07. 增速的两种读法 — 四区域 dumbbell（实心 = 报告口径 / 空心 = 汇率中性），红线段 = 汇率影响；右侧两列给出金额口径
08. 用户与参与度 — **巨字 `970` 与其单位共基线，规线从这一组接出**；直播的两个占比（共用 0—10% 轴）+ 十格计数（分母不同，不共轴）+ 本季代表作观看次数
09. 成本与效率 — 四项成本费用 × 七列紧凑表（金额 / 同比 / 占营收比 / 利润率影响），合计行闭合
10. 利润率桥（反相）— **巨字 `−0.69` 的基线就是四段瀑布的零轴**；技术与开发一项占全部下滑的 84%
11. 超预期项与未达标项 — 双栏对照，每项标注对标基准（vs 公司指引 / 去年同期 / 上一季度）
12. 风险 — 六行行表，每行「风险 · 本季证据 · 观察指标 · 证据出处（公司披露 / 本 deck 计算 / 本 deck 观察）」
13. 下季度重点（反相）— Q3 指引 + 全年目标完成度条 + 五项已宣布行动
14. 口径与来源 — 五条编号来源 + 十一条口径说明 + 免责

## Fonts & Colors
**字体（刻意只有两种）**
- 拉丁 / 数字：**Helvetica Neue**（瑞士派本尊；等高 lining 数字，巨字与表格数字都不会高低起伏；跨平台回退 Arial / Helvetica）
- 中文：**Hiragino Sans GB**（macOS 渲染安全；跨平台可回退 Microsoft YaHei / Noto Sans CJK SC）。**刻意不用 PingFang**——它在 LibreOffice 下会渲染成手写体
- **没有第三种字体**。眉标、页码、刻度栏、脚注全部走 Helvetica Neue，靠**字重（Regular / Bold）与字距（tracking）**区分角色——这正是瑞士国际主义的核心教条：层级由字号与字距承担，不由字体家族承担
- 全 deck 只有六个字号 token：`7 / 9.5 / 12 / 18 / 20 / 26`，另加巨字 `90 / 110 / 140`。任何一页不超过五级
- 组件已对每个 run 自动补 `<a:ea>` CJK 字体，中英混排不串字、不 tofu
- 负号用 ASCII 连字减号而非 U+2212：实测 LibreOffice 会把 U+2212 按东亚宽度渲染（无论 `<a:latin>` / `<a:ea>` 怎么标），在「同比 −28.0%」里撑出一个刺眼的空格；ASCII 减号紧贴数字，也是财务表格的通行做法
- 所有文本框左右内边距归零，文字墨迹与规线端点落在同一条网格线上

**配色（语义色系统，一色一义）**
- 画布：近白 `#F4F4F2`；主墨：**纯黑 `#000000`**
- 次墨 `#55554F`（7.4:1）· 三级墨 `#6E6E68`（4.66:1）· 发丝线 `#C9C9C3` · 刻度线 `#D2D2CC`
- **强调红 `#D0021B`（5.15:1）= 变化量 / 差额，且仅此一义**：同比 Δ、与目标的差、汇率影响 Δpt、瀑布段、增量与存量的错位。**存量与水平值一律纯黑**——包括净债务这类由两个存量相减得到的余额（它是余额，不是变化量）；序号、编号、来源标记也一律纯黑。正负号由**几何**编码（条在轴的哪一侧、点在哪一端、红段落在目标线左还是右），绝不引入第二种颜色——这是整套系统里最省力也最有效的一条纪律
- 灰阶 `#000000 / #4A4A46 / #8E8E88 / #C4C4BE` **只用于同一个量的份额切分**（分区域占比条），不作类别色
- 反相语域（仅 P10 诊断 / P13 决策两页）：底 `#111111`、字 `#FFFFFF` / `#A8A8A2`、发丝线 `#3A3A36`、强调红提亮为 `#FF4A5E`（同一语义，为反相底保证 5.75:1）。「**反相 = 需要停下来的两页**」，成族出现而非孤例；封面保持近白
- **无渐变、无圆角、无阴影、无卡片填充、无图标、无配图**。所有内容直落画布，只用发丝线分隔
- 签名动机「**刻度栏**」：每页左侧一把 14 格刻度尺，当前页刻度加长转黑并标页码——既是导航，也是「这份 deck 是量出来的」的宣言
- 签名手法「**巨字压栏**」：主角数字设到 90–140pt，**其基线替代该页本应绘制的横向规线**，规线只画到巨字边缘为止（P02 / P08 / P10）。巨字所载数值在同页均以正文字号复现一次，保真与可读性不依赖巨字

**网格**：12 栏（外边距 0.62in 对称，栏间距 0.12in，栏宽 0.62in，栏距 0.74in），0.18in 基线行。所有元素落在栏边界上；四种标题处理（粗规线 / 无线右戳 / 红竖条 / 上方发丝线）各占 25% 轮换，相邻页不重样。

**图表**：全部由原生形状按数据推导坐标绘制，可在 PowerPoint 中逐个元素选中编辑。所有量值条零基线，轴宽覆盖每一根柱，数值→坐标统一走同一个映射器，几何与数字永不脱节。

**可移植性**：`.pptx` 只存字体名。换机打开若无 Helvetica Neue / Hiragino Sans GB，会回退到 Arial / Microsoft YaHei（度量略变，网格与版式不塌）。本模板使用 macOS 系统字体 Helvetica Neue 与 Hiragino Sans GB；在 Windows 上建议替换为 Arial + Microsoft YaHei，或安装 Helvetica Neue / Noto Sans CJK SC 以获得一致效果。
