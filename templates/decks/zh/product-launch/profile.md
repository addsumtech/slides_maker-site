# 树莓派 5 —— 一场产品发布会主题演讲

为 slide-maker 公开模板库做的旗舰级示例 deck：一场**电影感的暗场产品发布会**，按真实、可溯源的
标准来做，而不是一份填满假文的样机。这些页面上的每一条规格、每一个倍数、每一个价格，都引自
Raspberry Pi Ltd 的官方文件。真正可复用的是那套观感 —— 一个纵深渐变的礼堂，一道贯穿全篇的连续
灯光弧线，规格数字是整页画面唯一的光源：换掉产品，这套系统仍然成立。

## Template File

- `template.pptx` —— 可编辑的 16:9 deck（原生文本、形状，以及一张可编辑的原生图表；在
  PowerPoint / Keynote 里完全可改）。
- `render/slide01.png … slide13.png` —— 每页一张 1920×1080 PNG（版式实证）。
- `build_pi5.py` —— 唯一事实来源的构建脚本（重跑即可端到端重新生成整份 deck）。
- `assets/generated/` —— 六张无文字的氛围底图，外加 `manifest.json`，即生成它们的原始提示词。
- `assets/icons/` —— 第 7、10、11 页用到的一组重新着色的 Tabler 图标。
- `assets/cache/` —— 派生位图（数字倒影、径向光晕），按需重建。

## Summary

**这是什么。** 一份 13 页的中文树莓派 5 产品发布会 deck，走的是真实发布会的叙事形状：冷开场 →
一个核心命题 → 主角揭幕 → 规格墙 → 三个标志特性 → 实测性能 → 生态 → 价格与供货 → 收尾一句话 →
来源。每一个数字都能追到一手来源 ——《Raspberry Pi 5 Product Brief》（2026 年 4 月发布）、树莓派
自己的发布博文与跑分博文、两个产品/公告页面、三篇价格说明，以及 Raspberry Pi Holdings 的 FY2025
财报 —— 并在使用它的那一页的脚注条里标明出处，完整清单放在第 13 页。没有任何估算、凑整或推断；
树莓派没有公布的数字，deck 就不写。凡是官方**已公布**而非本文档计算出来的倍数，页面上都会说明。
两份一手文件说法不一致时，deck 会点明自己采信了哪一份。2026 年的几轮涨价没有被藏起来：价格阶梯上
带着一道灰色刻度，标出每个型号最初卖多少钱。

**适合什么场合。** 任何需要在暗场里落地、并且事后要让人信服的发布或揭幕：硬件发布、产品主题演讲、
版本发布公告、以规格为主线的技术揭幕、大会开场主题演讲、路线图式的「我们交付了什么」汇报。它适合
**有真实公开数字**的主题 —— 整套视觉系统就是围绕「把一个规格数字当作主视觉」建起来的，所以内容
里有硬事实可上屏，它才吃得饱。默认是一份**自读 / 屏幕共享**用的 deck（静态，没有点击式动画构建），
如果要现场讲，每一页的备注里都写好了口播稿。

**怎么复用。** 把*内容*当成一个做完的范例，把*视觉系统*当成真正的资产。配色、字体搭配、发光数字
的辅助函数、`HORIZON` 灯光弧线、四种标题处理方式、脚注引用条，全都在 `build_pi5.py` 顶部定义一次，
所以换皮只需要改几处：换掉三个语义色、换掉字标字符串、换掉底图，再把你自己的数字倒进去。这套结构
之所以撑得住，是因为它是一个*形状*，不是装饰 —— 冷开场、一个命题、一次揭幕、一面证据墙、三个佐证、
实测结果、一个生态、一个价格、一句话。换掉内容，它照样成立。

## Structure（逐页）

1. **冷开场** —— 一张全出血暗色底图，一个被点亮的数字：**2016**，RP1 立项研发的那一年。此时还没有
   出现产品名。
2. **一个核心命题** —— 「第一次，全尺寸树莓派运行在自家设计的芯片之上。」，下面压着三个事实：
   自 2016 年起、$15m、台积电 40LP。
3. **主角揭幕** —— 数字 **5** 单独占据展示级字号，被点亮，并在舞台地面上留下倒影，配上「全能计算机。」
   与三条头条规格。*（本文档的标志性页面。）*
4. **规格墙** —— 八个数字直接放在画布上，完全不用卡片：数字**本身**就是版式，而且只有这块板子上
   **全新**的那两个（16 Gb/s 链路和那一条 PCIe 通道）是亮的。剩下的规格作为一条等宽字条沿底部铺开。
5. **标志特性 01 —— BCM2712** —— 用原生形状画出的缓存层级（4 × Cortex-A76 → 2 MB 共享 L3 →
   LPDDR4X-4267），右侧配一条 **2–3×** 的结论轨。
6. **标志特性 02 —— RP1** —— 拓扑图：BCM2712 经一条 4 通道 PCIe 2.0 链路以 16 Gb/s 接入 RP1，
   再扇出到每一个接口，下方写明 ×2 / ×3 / ×2 的带宽提升。*（灯光弧线在这里到达峰值。）*
7. **标志特性 03 —— PCI Express** —— 一个主角 **×1** 站在本文档自己那束光的光池里，讲清一条对外
   开放的通道能换来什么，并把树莓派自己关于转接板的限定语照实写出来，而不是藏起来。
8. **实测** —— **×2.4** 作为整页的光源，旁边是一张可编辑的原生柱状图，画的是树莓派自己跑的
   Geekbench 6.2 数据（340 → 764，723 → 1,604）。*（最有说服力的一页。）*
9. **实测，日常场景** —— 一块 before→after 的哑铃图板，覆盖五项真实负载，每一行都带着自己那条已公布
   的倍数，署名 Core Electronics，由树莓派博文转载。
10. **生态** —— **7500 万以上**的装机量当主角，旁边是三样真的能插上去的东西（MIPI、AI HAT+ 2、HAT+ 标准），
    压在一片点亮的板卡场景之上。
11. **价格与供货** —— 一条从 $45 到 $305 的价格阶梯，从零起算，每个容量版本都标出它最初卖多少，旁边是供货与
    生命周期两组事实。
12. **收尾一句话** —— 「全能计算机。」压在一张全出血的地平线上，再加上 2036 年的那句承诺。
13. **来源说明** —— 八份一手来源，编号列出，并注明各自提供了哪些数字。

## Fonts & Colors

**字体（按角色配对）。**
- **Futura** —— 展示体：所有拉丁标题、所有陈述行，以及**每一个主角数字**。几何、电影感，且是等高
  数字字体，所以「2016」「×2.4」「$305」在 148 pt 下仍然等高、单行不断。它默认行距非常松，所以
  deck 在展示级文本块上设 `line_spacing≈0.88`，并且每个展示块的高度都从真实字体度量算出，而不是用
  `pt/72` 估。
- **Hiragino Sans GB（冬青黑体简体中文）** —— 所有汉字。它通过 `<a:ea>` 挂在每一个 run 上，拉丁字母
  和数字仍留在 Futura / Helvetica Neue / Menlo 里，所以中文版和英文版是同一套版式、同一套数字主视觉，
  只是语言换了。这个字体族只有 W3 / W6 两个字重，正好对上 deck 里「正文 regular / 标题 bold」的两级
  用法：`bold=True` 落到 W6。**刻意不用 PingFang**：LibreOffice 会把它替换成一款手写体，渲染出来的
  PNG 就不能当版式证据了。
- **Helvetica Neue** —— 正文里的拉丁部分、图注、图示标签、图标行文案。
- **Menlo** —— 等宽装饰件：加了字距的眉标、规格字条、脚注引用、页脚字标锁定与页码。这是 deck 里那把
  安静的「工程」嗓音。
- 字号阶梯：四个文本档位（8.0 微型 / 9.4 装饰 / 11.0 小号 / 12.5 正文），加一个标题档位（27），
  再加每页各自的主角字号 —— 所以任何一页都不会临时发明一个字号。

**配色 —— 「Auditorium」，一份跑在渐变画布上的语义契约。**
- **画布：** 纵向渐变，从 `#03060F`（近黑，顶部）经 `#060C24` 到 `#0B1435`（深靛蓝，底部）。
  面板 `#101B40`，细线 `#24345F`。
- **青 `#35E0F0`** = *芯片与实测性能* —— BCM2712、RP1、内部那条 16 Gb/s 链路、每一个实测出来的
  ×N、眉标以及标示性细线。这是 deck 里「这是我们自己造的」那个色。
- **紫 `#9A7BFF`** = *接口，以及插在接口上的东西* —— USB、HDMI、PCIe 通道、40 针排针、MIPI、HAT+、
  AI HAT+、M.2。
- **树莓红 `#F2537E`** = *产品本身及其商业事实* —— 内存上限、价格阶梯、装机量。
- **钢蓝 `#6E86B4`** = *树莓派 4*，上一代：在图表里，旧数字不发光。
- 文字：主色 `#EDF3FF` · 次级 `#AEBFDD` · 弱化 `#7E93BC`。每一个文字色相对画布都过 4.5:1，规格墙上
  那一层没点亮的数字也过大字号 3:1 的线 —— 这两条都在构建脚本里断言过，一页都还没画就先验完。
- **灯光弧线：** 地平线光晕不是一个常量。一张 `HORIZON` 表按页索引强度，光从封面的地板一路爬升到
  RP1 那页的满场泛光，再落回收尾页的极光 —— 是一道连续的弧线，而不是十三页各自打光。
- **唯一的标志性手法：** 让一个规格数字成为整页唯一的光源 —— 一团柔和的径向光晕，加上一道在舞台
  地面上镜像、压扁、渐隐的倒影。两者都做成位图而非形状，所以在 PowerPoint、Keynote 和 PNG 导出里
  渲染完全一致。完整效果只出现在三页（1、3、8）；第 4 页把同一个想法拿去做结构上的活儿 —— 数字变成
  版式本身，八个里只点亮两个。

*字体替换提示：* Futura、Helvetica Neue 和 Menlo 是 macOS 系统字体，Hiragino Sans GB 同理。`.pptx`
存的是字体**名字**而不是字体本身，所以在 Windows 或 Linux 上会被替换 —— 版式还在，但字的性格会变。
想要完全可移植，改 `build_pi5.py` 顶部的 `FUT` / `HN` / `MONO` / `HANS`（Futura 可换 Century Gothic
或 Jost，Helvetica Neue 换 Arial，Menlo 换 Consolas，Hiragino Sans GB 换 Microsoft YaHei 或
Noto Sans CJK SC），或者直接装上原字体。`render/` 里的 PNG 就是这份 deck 应有样子的参考。
